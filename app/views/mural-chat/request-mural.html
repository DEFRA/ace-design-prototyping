Request a Mural board

Use this service to request a new Mural board to be connected. Once approved, the board will be available for AI-assisted analysis.

Before you start

You will need:

  • the Mural workspace ID
  • the Mural board ID
  • the name or email of the Board Owner who will approve the request
Only service administrators can request new boards. If you are not an admin, you will need to ask one to submit the request on your behalf.
